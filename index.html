Get the App

Install this on a phone or computer so it opens like a normal app, or download the app file to share.

The downloaded file keeps your current business name, logo and theme, but not your sales records. It works offline in any browser. Use Export Backup below to move records between devices.

Backup & Restore (not a report)

This makes a special backup file used only to restore your records on this or another device. It is not meant to be read. For a readable report, use the Reports tab (Excel or PDF). Importing a backup replaces the current records.

Do not delete browser data without a backup. This tool has no login or cloud sync.
